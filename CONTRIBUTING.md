# Contributing to Skills Introduction to GitHub

Thank you for your interest in contributing! This repository is designed to help people learn GitHub fundamentals.

## Reporting Issues

When creating an issue, please provide the following information to help us address your needs effectively:

### Required Information

1. **Main Problem or Request**
   - Clearly describe what you're trying to accomplish or what problem you've encountered
   - Be specific about the issue or feature request

2. **Steps to Reproduce (for bugs)**
   - List the exact steps that led to the problem
   - Include any error messages you received
   - Specify your environment (OS, browser, etc.)

3. **Context and Files Involved**
   - Mention which files or code sections are relevant
   - Provide code snippets if applicable (use markdown code blocks)
   - Link to specific lines using GitHub's line linking feature

4. **Expected Outcome**
   - Describe what you expected to happen
   - Explain what actually happened instead
   - Include screenshots if relevant

### Issue Templates

We provide issue templates to make it easier to report:
- **Bug Reports**: For reporting problems or unexpected behavior
- **Feature Requests**: For suggesting new features or improvements
- **Questions**: For asking questions about the repository

### Code Contributions

If you'd like to contribute code:

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes with clear commit messages
4. Test your changes (run `cargo test` if modifying Rust code)
5. Submit a pull request with a clear description

### Code Style

- For Rust code, follow standard Rust conventions
- Run `cargo fmt` before committing
- Run `cargo clippy` to check for common mistakes
- Ensure all tests pass with `cargo test`

## Questions?

If you have questions about contributing, feel free to open an issue with the "Question" label.
